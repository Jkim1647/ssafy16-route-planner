| 발견 | 원인 | 수정 | 테스트 |
|---|---|---|---|
| 날짜를 도착 시각 칸에 넣음(gpt-5-nano) | 최소 모델 추출 오류 | 한국어 날짜·시각 보조 파서, 모델 gpt-6-luna로 전환 | `test_ko_time.py`, `test_analyze_fixes_date_in_time_field` |
| 토요일 날씨 '범위 밖' | 3일 뒤 예보는 3시간 간격 | ±3시간 내 가장 가까운 예보 시각 사용·표시 | `test_weather_three_hourly_uses_nearest_slot` |
| KTX 경로가 안 나옴 | 가장 가까운 역만 봄 | 첫 시도 역 2곳, KTX 정차역 우선 | `test_find_stations_prefers_ktx` |
| 재계획 때 같은 Tool 반복 호출(이상 징후 판정이 발견) | 실행 단위 재사용 없음 | 실행 단위 결과 재사용 | `test_replan_reuses_results_within_run_no_duplicates` |
| Worker LLM 15회(비교 실험) | 고칠 인자 없는 실패도 LLM 판단 | `TUNABLE` 규칙 | `test_worker_no_llm_when_no_tunable_args` |
