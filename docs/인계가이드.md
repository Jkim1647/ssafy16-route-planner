# 인계 가이드 — 이동 플래너를 처음 맡는 분께

전체 그림(구조도·요청 흐름·Agent 그래프)은 [README 0장](../README.md#0-한눈에-보기-처음-보는-분께)에 있습니다. 이 문서는 **직접 고치고 늘릴 때** 필요한 것만 모았습니다.

## 1. 처음 1시간

| 순서 | 할 일 | 확인 |
|---|---|---|
| 1 | `python -m venv .venv` → `pip install -r requirements.txt` | |
| 2 | `.env.example`을 `.env`로 복사, 키 입력(README 3장) | `GET /api/config/status`의 `keys`가 모두 `true` |
| 3 | `pytest` | 전부 통과(외부 API를 부르지 않음 — `tests/conftest.py`가 `requests.get/post`를 막음) |
| 4 | `node --test tests/frontend/question.test.mjs tests/frontend/tradeoff.test.mjs tests/frontend/reminder.test.mjs` | 화면 쪽 순수 계산 테스트 |
| 5 | `uvicorn backend.main:app --port 8000` + `python scripts/serve_frontend.py 5500` | http://127.0.0.1:5500 |
| 6 | 화면에서 예시 질문 한 번 → 오른쪽 '실행 과정' 탭 | 분석 → 계획 → Tool 호출 → 판단 → 응답이 순서대로 보임 |
| 7 | `실행 로그` 메뉴 | 방금 요청의 이벤트·이상 징후 판정 |

로그인을 끄려면 `.env`에 `AUTH_REQUIRED=false`(이 컴퓨터 사용자 `local` 한 명으로 동작).

## 2. 새 Tool(외부 API) 추가하기

예: "주차장 정보" Tool을 붙인다고 할 때.

1. **`backend/tools/parking.py`** 를 만든다. 지켜야 할 규약:
   - 결과는 항상 `ok(data)` 또는 `fail(코드, 메시지)`(`tools/base.py`). 코드는 `BAD_ARGUMENT`·`INVALID_KEY`·`NO_DATA`·`UPSTREAM_ERROR`·`RATE_LIMITED` 등 기존 것을 쓴다 — Agent가 코드를 보고 재시도·건너뛰기·재계획을 정한다.
   - HTTP는 `tools/http.py`의 `fetch_json`만 쓴다(오류 메시지에 키가 든 URL이 섞이지 않게).
   - 같은 입력을 반복해서 부르지 않게 `default_budget().cached_call("api이름", args, ttl초, fn)`로 감싼다. 하루·월 한도가 있으면 `tools/budget.py`의 `_limits()`에 추가.
   - "HTTP 200인데 본문이 오류"인 공공 API는 **캐시 전에** `fail`로 바꾼다(오류가 캐시되지 않게 — `tour_festival.py`의 `fetch()` 참고).
   - 파일 끝에서 `register(Tool(name=…, description="언제 부르는지", parameters=JSON Schema, func=…, kind="external"))`.
2. **`backend/tools/catalog_all.py`** 에 import를 추가(등록은 import 부수효과).
3. Agent가 쓰게 하려면 **`backend/agent/executor.py`** 의 `PLAN_TRIP`에 작업 `("t16", "parking_tool", "설명", None)`을 넣고, `run_plan_trip` 안에서 `call_tool(ctx, "t16", "parking_tool", {...})`로 부른다. 결과를 카드 경고로 붙이려면 `ctx.notes`에 문장을 넣으면 된다(`_festivals` 참고).
4. **테스트**: `tests/tools/test_parking.py` — `tests/helpers.py`의 `route_get(monkeypatch, [(조건, 응답 본문)])`으로 가짜 응답을 넣는다. 실제 응답 샘플은 `tests/fixtures/`에 저장해 `load("이름")`으로 읽는다.
5. **문서**: `docs/Tool정의서.md` 표, README 4장(이용 조건).

## 3. 새 API 경로·화면 추가하기

- **API**: `backend/api/routes.py`에 함수 하나. 입력·출력 형식은 `backend/schemas.py`(Pydantic, 길이·범위 상한을 꼭 둔다). 저장소는 `_c(request).plans` 처럼 `backend/container.py`에서 꺼낸다.
  - 상태를 바꾸는 POST는 `content-type: application/json`만 받게 한다(다른 사이트 폼 위조 차단 — `/plans/{id}/calendar` 참고).
  - 바꾼 뒤 `docs/API명세서.md`와 `docs/openapi.json`을 갱신:
    `python -c "import json; from backend.main import app; open('docs/openapi.json','w',encoding='utf-8').write(json.dumps(app.openapi(), ensure_ascii=False, indent=1))"`
- **화면**: `frontend/js/pages/새페이지.js`(맨 위에 한 줄 역할 주석) → `frontend/js/main.js`의 `routes`와 상단 메뉴에 추가. 서버 호출은 `api.js`의 `api(path, {method, body})`(쿠키 포함, 401이면 로그인 화면으로). 페이지를 옮겨도 남아야 하는 상태는 `store.js`.
  - 빌드 도구가 없다(CDN의 Vue·Vue Router·Leaflet, `index.html`에 버전·무결성 해시 고정). 라이브러리를 추가하면 같은 방식으로.
  - 순수 계산은 `question.js`처럼 의존성 없는 파일로 빼면 `node --test`로 시험할 수 있다.

## 4. 데이터와 사용자 구분

- SQLite 하나(`data/app.db`): `plans`(이동 계획) · `places`(내 장소) · `runs`·`run_events`(실행 로그) · `anomaly_reports`(이상 징후) · `users` · `local_calendar`.
- 스키마 변경은 `backend/db/database.py`의 `init_db`에서 **있으면 건너뛰는** `ALTER TABLE`로(기존 데이터 보존). 예: `share_token` 열.
- **사용자 구분 규칙**: 요청마다 `auth/middleware.py`가 쿠키(JWT)를 읽어 현재 사용자를 컨텍스트에 둔다(`auth/context.py`의 `current_user_id()`). 저장소는 모든 조회·수정에 `user_id`를 조건으로 건다. **새 테이블에도 `user_id`를 두고 같은 규칙을 지킬 것** — 안 그러면 다른 사람 데이터가 보인다.
- 로그인 없이 열리는 경로는 `auth/middleware.py`의 `PUBLIC`(`/api/auth/`, `/api/config/status`, `/api/shared/`)뿐.

## 5. 외부 API 한도 — 꼭 지킬 것

| API | 한도 | 장치 |
|---|---|---|
| ODsay | **하루 30회** | 7일 캐시, 요청당 4회 상한, 남은 6회는 예약(`QUOTA_USE_RESERVE`), 넘으면 택시 기준 |
| ITS 돌발정보 | **월 100회** | 실행당 1회, 하루 4회 |
| GMS(LLM) | 교육용 한도 | 요청당 최대 2회(조건 뽑기·답장) |
| FOSSGIS 보행 경로 | 초당 1회 | 서버에서만, 7일 캐시, `WALK_ROUTE_ENABLED=false`로 끔 |

사용량은 화면 상단(`ODsay 오늘 n/30회`)과 `GET /api/config/status`. 시험할 때는 같은 질문을 반복하면 캐시가 쓰여 한도를 거의 쓰지 않는다.

## 6. 비밀값과 커밋하면 안 되는 것

`.gitignore`에 있음: `.env` · `token.json` · `credentials.json`(Google) · `data/app.db`(사용자 데이터) · `data/chroma/` · `data/cache/` · `data/*.bak-*`.
- 키는 코드·로그·오류 메시지에 남기지 않는다(`fetch_json`이 URL을 숨김, `/api/config/status`는 키 **있음/없음**만).
- 화면 캡처·시연은 로컬 캘린더로(`CALENDAR_BACKEND=local`) — 실제 Google 일정 제목이 찍히지 않게.

## 7. 알아 둘 한계·함정

- **이 컴퓨터에서만 열림**: 서버가 `127.0.0.1`에서만 받는다(`TrustedHostMiddleware`). 공유 링크도 배포 전에는 같은 컴퓨터에서만 열린다.
- **Google 로그인은 테스트 모드**일 수 있다 → 등록한 테스트 사용자만 로그인. 리디렉션 URI 포트(8000/8001)가 `.env`의 `GOOGLE_REDIRECT_URI`와 같아야 한다.
- **Windows**에서 `python -m http.server`는 `.js`를 `text/plain`으로 보내 화면이 안 뜬다 → `scripts/serve_frontend.py`.
- 화면이 예전 모습이면 브라우저 캐시 — **Ctrl+Shift+R**.
- 한국어 날짜·시각은 LLM이 틀려도 `agent/ko_time.py`가 보정한다. "밤 12시"처럼 모호한 표현은 일부러 읽지 않는다(되묻기).
- 버스 동선은 정류장을 경유지로 넣은 **자동차 길찾기 추정**이라 실제 노선과 조금 다를 수 있다. 열차는 역 사이 직선.
- 좌석·실시간 지연·혼잡은 공개 API로 알 수 없어 계산에 넣지 않고 "확인 불가"로 안내한다.

## 8. 바꾼 뒤 확인 순서

1. `pytest` + `node --test …`(1장 4번)
2. 화면에서 예시 질문 1번, 질문 만들기 1번(두 곳), 여러 동선 1번(세 곳)
3. `실행 로그`에서 이상 징후 판정이 `ok`인지(중복 호출·계획 외 호출이 없어야 함)
4. API를 바꿨으면 `docs/API명세서.md`·`openapi.json`, 기능을 바꿨으면 README 2장·`docs/검증결과.md`
